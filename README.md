# Chuyenmon26

Bộ ôn tập chuyên môn (chạy bằng GitHub Pages).

## Cấu trúc (6 file, để chung một thư mục)
- `index.html` – trang chủ chọn chủ đề
- `chuyen-mon.html` – bộ câu hỏi Chuyên môn
- `nghi-quyet.html` – bộ Nghị quyết (kèm nhạc)
- `tai-lieu-on-tap.html` – tài liệu ôn tập
- `hanh-trang.js` – hiệu ứng chuyển cảnh dùng chung, chứa sẵn toàn bộ ảnh
- `nhac-chuong3.mp3` – nhạc của trang Nghị quyết

## Cập nhật
Up file mới đè lên file cùng tên, đợi 1-2 phút rồi bấm Ctrl + Shift + R để xem bản mới.
